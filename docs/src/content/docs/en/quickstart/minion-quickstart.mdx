This guide builds a small minion flow:

1. Create a minion model.
2. Create a card that summons it.
3. Add a clickable action to the minion.
4. Create a card that targets minions.
5. Create a generated card bound to a specific minion.

For complete examples, compare the code in `MinionLib.Example/Minions`, `MinionLib.Example/Cards`, `MinionLib.Example/Actions`, and `MinionLib.Example/Powers`.

## Pick base classes

If your project does not use BaseLib or RitsuLib, inherit MinionLib's native classes. If it does, install the matching dependency as described in [Environment Setup](/MinionLib/en/quickstart/environment/) and inherit the generated adapter classes.

<Tabs syncKey="adapter">
    <TabItem label="Vanilla">

        ```csharp
        using MegaCrit.Sts2.Core.Entities.Cards;
        using MinionLib.Action;
        using MinionLib.Component;
        using MinionLib.Component.Core;
        using MinionLib.Minion;

        public abstract class MyMinionBase : MinionModel;

            int cost,
            CardType type,
            CardRarity rarity,
            TargetType target)
            : ComponentsCardModel(cost, type, rarity, target);
        ```

## Create a minion

A minion is a specialized monster model. A minimal implementation usually provides visuals, initial HP, and summon initialization.

<Tabs syncKey="adapter">
    <TabItem label="Vanilla">

        ```csharp
        using MegaCrit.Sts2.Core.Commands;
        using MegaCrit.Sts2.Core.Entities.Players;
        using MegaCrit.Sts2.Core.GameActions.Multiplayer;
        using MegaCrit.Sts2.Core.Models.Powers;
        using MinionLib.Minion;
        using MinionLib.Powers;

        public sealed class MyMinion : MinionModel
        {
            public override int MinInitialHp => 6;
            public override int MaxInitialHp => 6;
            protected override string VisualsPath =>
                "res://Example/MinionTest/scenes/creature_visuals/pettest_attackaka.tscn";

            public override async Task OnSummon(
                PlayerChoiceContext choiceContext,
                Player owner,
                MinionSummonOptions options)
            {
                var self = Creature;

                if (options.MaxHp is decimal maxHp)
                    await CreatureCmd.SetMaxAndCurrentHp(self, maxHp);

                if (options.PrimaryStatAmount is decimal strength && strength > 0m)
                    await PowerCmd.Apply<StrengthPower>(
                        choiceContext, self, strength, owner.Creature, options.Source);

                await PowerCmd.Apply<MinionGuardianPower>(
                    choiceContext, self, 1m, owner.Creature, options.Source);
            }
        }
        ```

    </TabItem>

## Create a summon card

Use`MinionCmd.AddMinion<T>()` to summon a minion.`MinionSummonOptions` carries HP, primary stats, source, and position.

<Tabs syncKey="adapter">
    <TabItem label="Vanilla">

        ```csharp
        using MegaCrit.Sts2.Core.Entities.Cards;
        using MegaCrit.Sts2.Core.GameActions.Multiplayer;
        using MinionLib.Component;
        using MinionLib.Component.Core;
        using MinionLib.Commands;
        using MinionLib.Minion;

        public sealed class SummonMyMinionCard()
            : ComponentsCardModel(1, CardType.Power, CardRarity.Rare, TargetType.Self)
        {
            protected override async Task OnPlay(
                PlayerChoiceContext choiceContext,
                CardPlay cardPlay,
                ComponentContext componentContext)
            {
                _ = await MinionCmd.AddMinion<MyMinion>(choiceContext, Owner, new MinionSummonOptions(
                    MaxHp: 8m,
                    PrimaryStatAmount: 2m,
                    Source: this,
                    Position: MinionPosition.Front));
            }

            protected override void OnUpgrade(ComponentContext componentContext) { }
        }
        ```

    </TabItem>

## Create a clickable action

An action is a power - like model that can be clicked.After it is applied to a minion, the player can click the minion or action icon to resolve it.

<Tabs syncKey="adapter">
    <TabItem label="Vanilla">

        ```csharp
        using MegaCrit.Sts2.Core.Commands;
        using MegaCrit.Sts2.Core.Entities.Cards;
        using MegaCrit.Sts2.Core.Entities.Creatures;
        using MegaCrit.Sts2.Core.Entities.Powers;
        using MegaCrit.Sts2.Core.GameActions.Multiplayer;
        using MegaCrit.Sts2.Core.ValueProps;
        using MinionLib.Action;
        using MinionLib.Commands;

        public sealed class MyAttackAction : ActionModel
        {
            public override TargetType TargetType => TargetType.AnyEnemy;
            public override bool AutoRemoveAtTurnEnd => true;
            public override PowerType Type => PowerType.Buff;
            public override PowerStackType StackType => PowerStackType.Counter;

            protected override async Task OnAct(
                PlayerChoiceContext choiceContext,
                Creature? target)
            {
                if (target == null) return;
                var actor = Owner;

                await MinionAnimCmd.PlayBumpAttackAsync(actor, target);
                await CreatureCmd.Damage(choiceContext, target, 4m, ValueProp.Move, actor);
            }
        }
        ```

    </TabItem>
    <TabItem label="BaseLib">

## Target minions

MinionLib provides`MinionTargetTypes` for card and power targets.

```csharp
using MegaCrit.Sts2.Core.Commands;
using MegaCrit.Sts2.Core.Entities.Cards;
using MegaCrit.Sts2.Core.GameActions.Multiplayer;
using MegaCrit.Sts2.Core.Models.Powers;
using MinionLib.Component;
using MinionLib.Component.Core;
using MinionLib.Minion;
using MinionLib.Targeting;

public sealed class EmpowerMinionCard()
    : ComponentsCardModel(1, CardType.Skill, CardRarity.Uncommon, MinionTargetTypes.AnyMinion)
{
    protected override async Task OnPlay(
        PlayerChoiceContext choiceContext,
        CardPlay cardPlay,
        ComponentContext componentContext)
    {
        if (cardPlay.Target is not { Monster: MinionModel } target) return;

        await PowerCmd.Apply<StrengthPower>(choiceContext, target, 2m, Owner.Creature, this);
        await PowerCmd.Apply<DexterityPower>(choiceContext, target, 2m, Owner.Creature, this);
    }
}
```

Common target types live in `MinionLib.Targeting.MinionTargetTypes`, including`AnyMinion`, `AnyMinionOrOwner`, `AllMinions`, and`AllCreatures`.

## Guardian and positions

The built - in `MinionGuardianPower` lets a minion intercept damage for its owner:

```csharp
await PowerCmd.Apply<MinionGuardianPower>(choiceContext, self, 1m, owner.Creature, options.Source);
```

Summoning can specify a position:

```csharp
public enum MinionPosition
{
    Front,
    Back,
    FrontUpper,
    BackUpper,
    Upper
}
```

Position affects visuals and mechanics that depend on minion order.
